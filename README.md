## 📖 课程简介

本仓库为南昌大学「人机协同编程」课程的个人作品集，记录了团队在整个学期（第 1–16 周）中的实验项目与学习成果。通过每周的实验练习，我们逐步掌握编程基础、数据处理、可视化以及人工智能协同编程的核心技能。

## 📝 使用说明

1. 克隆本仓库到本地：
   ```bash
   git clone https://github.com/<你的用户名>/NCU-Human-AI-Programming.git
   ```
2. 进入对应周的实验目录，查看代码和文档
3. 每周实验完成后提交并推送到本仓库
